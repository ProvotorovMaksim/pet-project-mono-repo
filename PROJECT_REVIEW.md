# Технический обзор · Pet Project Monorepo — стенд VPN-сервисов

Оценка для позиции Junior Python Developer / Integration Engineer. Основание — статический анализ исходников, сохранённых в Git на коммите `4cafcf6`. Выводы о сценариях отказа требуют проверки в рабочем окружении.

## Сильные стороны

Проект показывает композицию автономных сервисов, отдельные хранилища и наблюдаемость в одном стенде.

## Слабые стороны и архитектурные замечания

`git submodule status` завершается ошибкой из-за отсутствующих записей в `.gitmodules`. Шлюз и VPN публикуют один и тот же хост-порт 8000. Команда `docker compose config --quiet` проверяет структуру, но не выявляет конфликт при привязке порта.

## Что проверить на демонстрации

Нужно восстановить воспроизводимое получение исходников, проверить итоговый Compose и зафиксировать контракты для внешних зависимостей.
